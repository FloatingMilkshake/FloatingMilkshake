## Looking for something?

I no longer publish my code on GitHub. (I do still contribute to other people's projects, so you may still see some of that.)

The increase in [often undisclosed and done without human oversight] LLM activity in open-source has driven me away from sharing my code publicly here. GitHub as a platform also seems to be going downhill, both in terms of encouraging LLM use (no I do not want to use Copilot) and stability/reliability.

If you're interested in any of my projects, I am still happy to share and discuss their source and inner workings. You can find my code on my Forgejo instance at [git.milkshake.services](https://git.milkshake.services/). If you don't see what you're looking for there, [ask me about it](https://floatingmilkshake.com/#contact)! It might be private, but I am happy to talk about most of my private projects too :3
